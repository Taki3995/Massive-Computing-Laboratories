El problema de la estructura original: El código MatrixMulKernelGeneral proporcionado por defecto utiliza un sistema de punteros unidimensionales (aBegin, aStep, bBegin, bStep) para iterar por los sub-bloques. Esta lógica asume obligatoriamente que las matrices son cuadradas y de dimensiones perfectas. Para romper esta restricción, debemos cambiar la forma en que iteramos, utilizando un sistema de coordenadas 2D.La fórmula a usar (Visto en clase): De acuerdo con el material del curso sobre cómo cargar un "Input Tile", calcularemos directamente la fila global (Row) y la columna global (Col) que le corresponde a cada hilo usando las fórmulas estándar de la cuadrícula (grid):   int Row = by * BS + ty;   int Col = bx * BS + tx;   Control de límites (Boundary Checks): Al igual que se hizo en la convolución 1D para evitar leer basura fuera del vector, dividiremos la matriz en 'tiles' (mosaicos) usando un bucle. En cada ciclo del bucle, el hilo calculará si la celda que intenta leer de A y B existe físicamente:   Para la matriz A, la fila Row debe ser menor a {MATRIX_A_ROWS} y la columna a extraer debe ser menor al ancho {MATRIX_A_COLS}. Si es falso, guardamos un 0.0 en la memoria compartida As.Para la matriz B, la columna Col debe ser menor a {MATRIX_B_COLS} y la fila a extraer menor a {MATRIX_B_ROWS}. Si es falso, guardamos un 0.0 en Bs.Escritura segura: Al finalizar la multiplicación del mosaico, validamos de nuevo con un if (Row < {MATRIX_A_ROWS} && Col < {MATRIX_B_COLS}) antes de guardar el resultado Csub en la matriz C.
